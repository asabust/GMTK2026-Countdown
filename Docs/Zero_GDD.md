## 0. 一页速查

### 0.1 核心体验

玩家被时间魔王诅咒，变成了发条小人。唯一资源 **Point（点数）** 同时代表生命、剩余时间、行动成本和货币。移动、攻击、受伤、购买与供奉都会改变点数；点数降到 `-1` 时失败。

玩家需要穿过 12×12 的迷雾森林，击败其他发条生物、回收点数、取得技能与物品，最后击败两阶段 Boss“哀叹之钟”重获自由。

### 0.2 核心循环

```text
标题
→ 进入 12×12 迷雾地图
→ 移动与发现事件
→ 接触普通怪物
→ Roll / 不 Roll 决定该实例生命
→ 读取敌人意图并战斗
→ 安全领取或贪婪
→ 商店 / 供奉 / 篝火 / 交换 / 宝藏
→ 两阶段 Boss
→ 胜利或点数跌至 -1
→ 重试或返回标题
```

### 0.3 关键数值

| 规则 | 当前值 |
|---|---:|
| 初始 / 最大点数 | 100 / 100 |
| 失败点数 | -1 |
| 移动成本 | 1 |
| 普攻成本 / 伤害 | 1 / 3 |
| 基础视野 | 半径 1，即 3×3 |
| 基础贪婪 | 50% 成功，2.5×收益 |
| 普通怪回合掉落倍率 | 80% / 70% / 60% / 50% / 45% |
| 地图 | 12×12 |
| 供奉上限 | 15 |

### 0.4 操作

| 场景 | 操作 |
|---|---|
| 地图移动 | `W / A / S / D` 或方向键 |
| 普攻 | `F` |
| 技能槽 1 / 2 / 3 | `Q / E / R` |
| 打开道具菜单 | `Z` |
| 使用道具槽 1～4 | `1 / 2 / 3 / 4` 或小键盘 |
| 从道具菜单返回 | `Esc` |
| 菜单与地图交互 | 鼠标 |

战斗没有独立的“防御”行动。玩家的一级战斗菜单是普攻、三个已获得技能槽和道具入口。

## 1. 设计支柱

1. **点数就是一切**：Point 同时是生命、时间、行动力和货币。
2. **未知路线，已知风险**：地图被迷雾覆盖，但已发现怪物的掉落规则和战斗中的下一意图必须清楚。
3. **每一步都是倒计时**：移动和攻击都有成本，绕路与战斗都必须衡量。
4. **贪婪必须由玩家确认**：高风险收益不能暗中触发。
5. **失败应可复盘**：点数变化通过 HUD、飘字、Toast 和音效说明来源。

## 2. Point 与失败规则

### 2.1 唯一资源

Point 用于：

- 玩家生命与倒计时。
- 地图移动。
- 普通攻击和技能。
- 商店购买。
- 供奉。
- 战斗伤害、偷取、奖励与恢复。

道具不是货币；藏品是被动规则修正。

### 2.2 数值边界

- `NumberResource` 初始值 100、最大值 100、最小值固定为 -1。
- 0 点仍存活；-1 点立即失败。
- 主动消费通常只允许支付后保持在 0 或以上。
- 探索时允许从 0 点向空地迈出最后一步，落地后变成 -1，再进入失败流程。
- 0 点接触敌人或交互物不收移动成本，仍可打开对应流程。
- 回复与奖励不会超过 100。

### 2.3 战斗中的 0 点

- 首次以 0 点进入玩家回合且仍有敌人时，可进行一次“挣扎”。
- 挣扎消耗 0，造成 1 点伤害，并推进回合；每场战斗一次。
- 挣扎已使用且没有其他合法零成本行动时，玩家回合会提示并自动跳过。
- 0 点击杀怪物后仍可从战斗奖励恢复。

### 2.4 新局重置

新游戏或重试会重置：

- Point。
- 背包中的道具和藏品。
- 已学技能及冷却。
- 玩家临时与本局状态。
- 场景、怪物、商店库存、宝藏和迷雾。

入口：`GameManager.StartNewGame()`。

## 3. 地图、移动与迷雾

### 3.1 地图

- `GameScene.unity` 的 Ground Tilemap 是完整的 12×12 地图，共 144 格。
- 玩家出生格为 `(0, 0)`。
- 仅允许上下左右移动，不允许斜向移动。
- 成功进入相邻空地支付 1 Point。
- 墙、边界或无效占位不移动、不收费。
- 玩家接触敌人或事件点时保持原位，也不支付移动成本。

### 3.2 占位与接触

- 玩家、普通怪和世界事件通常占 1×1。
- Boss 占 2×2。
- 目标为空地时移动；目标为敌人时开启遭遇；目标为交互物时打开面板。
- 战斗结束后玩家不会自动进入敌人原来的格子。
- 被消费的敌人 / 事件会释放占位；未消费事件保留并可再次接触。

### 3.3 迷雾

- `visionRadius = 1`，可见范围为以玩家为中心的 3×3 方形。
- 格子状态：未探索、已探索但不可见、当前可见。
- 移动完成后刷新视野；初始位置立即刷新，不额外收费。
- 普通怪未发现时隐藏；离开视野后隐藏实时战斗信息。
- Boss 为保证大尺寸美术可见，使用特殊的迷雾显示处理。
- 敌人不巡逻、不追踪，也不会因为进入视野而主动攻击。

### 3.4 朝向

- 敌人美术默认朝左。
- 只有玩家位于敌人右侧时，敌人 Sprite 才水平翻转。
- 进入遭遇时由 `EnemyActor.FacePlayer()` 更新。

### 3.5 当前场景内容

以下为 `GameScene.unity` 中的 Prefab 实例数：

| 内容 | 数量 |

| 小绒鸡 | 4 |
| 发条油掠夺者 | 4 |
| 惊魂匣 | 3 |
| 鼓鼓仓鼠 | 3 |
| Boss | 1 |
| 篝火 | 7 |
| 商店 | 3 |
| 供奉 | 3 |
| 交换点 | 2 |

## 4. 遭遇与回合

### 4.1 普通怪战前生命选择

第一次接触每个普通怪实例时打开 Roll 面板：

- **Roll**：在 `[MinHP, MaxHP]` 闭区间均匀随机。
- **不 Roll**：使用稳定生命。

```text
StableHP = min(MaxHP, floor((MinHP + MaxHP) / 2) + 1)
```

结果保存在怪物实例的 `ResolvedMaxHP` 与 `CurrentHP` 中；同一实例不会重复选择。Boss 不打开此面板，直接使用固定生命。

### 4.2 战斗阶段

`EncounterController` 的阶段顺序：

```text
Exploration
→ PreBattleHealthChoice（普通怪首次接触）
→ PlayerTurn
→ ResolvingPlayerAction
→ EnemyTurn
→ ResolvingEnemyAction
→ PlayerTurn 或 Reward
```

规则：

- 正式战斗开始时锁定敌人的第一条意图。
- 玩家选择普攻、技能、道具或挣扎。
- 行动合法后才支付成本和结算。
- 若敌人存活，执行先前展示的意图。
- 敌人回合结束后锁定下一条意图，再交还玩家回合。
- 战斗期间地图输入被锁定。

### 4.3 普攻与回合计数

- 普攻消耗 1 Point，基础伤害 3。
- 普攻、技能、道具和挣扎均计为一次玩家行动，并推进普通怪的击杀回合。
- 技能冷却和扳手持续时间也随对应玩家行动推进。
- 战斗效果由逻辑先结算，动画负责展示，不产生随机结果。

### 4.4 伤害顺序

玩家造成普通攻击伤害：

```text
基础 3
+ 本局供奉攻击加成
+ 当前扳手加成
→ 若嗜血有效，再乘嗜血倍率
```

玩家受到敌人攻击：

1. 守护者之盾抵扣。
2. 若仍有剩余伤害，少女的心事将该次攻击归零。
3. 应用最终伤害。
4. 检查是否降至 -1。
5. 敌人阶段结束后清除剩余护盾。

当护盾抵挡或少女的心事触发时，分别显示：

- `battle.item.shield_blocked`
- `battle.item.attack_negated`

### 4.5 临时状态跨战斗规则

- 扳手、守护者之盾和少女的心事是当前战斗的道具状态。
- 开始下一场遭遇时，未耗尽的上述状态全部清除。
- Boss 一阶段转二阶段属于同一场战斗，不执行该清除。
- 技能冷却在战斗结束、敌人逃跑、失败或 Boss 结算时清除。

## 5. 技能

技能配置位于 `Assets/Game/Data/Skills`，运行时由 `PlayerSkillController` 管理。三个技能通过各自的技能宝藏获得，重新开始游戏时清空。

| 技能 | 快捷键 | 消耗 | 冷却 | 当前效果 |
|---|---|---:|---:|---|
| 下劈（普攻） | F | 1 | 0 | 造成 3 点基础伤害 |
| 嗜血 | Q / 技能槽1 | 1 | 2 | 接下来 2 次普攻伤害 ×2 |
| 寄生 | E / 技能槽2 | 4 | 2 | 造成 6 伤害；若击杀，回复 3 Point |
| 复仇 / Multi-Slash | R / 技能槽3 | 3 | 3 | 攻击 2～3 次，每次 5 伤害；50% 为 3 次 |

补充：

- 未获得的技能槽不显示。
- 嗜血只强化普攻，不强化寄生、复仇或挣扎。
- 再次获得嗜血强化时不叠乘倍率，而是保证剩余强化次数至少为 2。
- 复仇过程中敌人提前死亡时停止剩余攻击。
- 正成本技能必须能支付且支付后不低于 0。

## 6. 怪物与意图

### 6.1 数值总表

| 怪物配置 | Roll 区间 / 固定生命 | 稳定生命 | 普攻 | 特殊行为 | 意图循环 |
|---|---:|---:|---:|---|---|
| 小绒鸡（易） | 8～12 | 11 | 2 | 啄击 3 | 等待 → 普攻 → 特殊 |
| 小绒鸡（难） | 10～14 | 13 | 2 | 啄击 3 | 等待 → 普攻 → 特殊 |
| 发条油掠夺者 | 12～15 | 14 | 4 | 喝酒 | 普攻 → 喝酒 |
| 惊魂匣 | 4～8 | 7 | 0 | 致死时过载爆炸 | 等待 |
| 鼓鼓仓鼠 | 9～15 | 13 | 2 | 偷点并逃跑 | 偷取 → 偷取 → 逃跑 |
| 哀叹之钟·一阶段 | 固定 25 | 25 | 4 | 强力击 7 | 普攻 → 蓄力 → 蓄力 → 强力击 |
| 哀叹之钟·二阶段 | 固定 15 | 15 | 3 | 偷取道具 | 普攻 → 普攻 → 偷取 |

### 6.2 小绒鸡

- 等待、普攻、啄击固定循环。
- 易 / 难使用不同生命区间，其他行为相同。

### 6.3 发条油掠夺者

喝酒占用敌人回合，并在执行时等权随机：

- 下一次普攻 +1。
- 自伤 2；可以因此死亡。
- 本回合晕眩，什么也不做。

喝酒意图只预告喝酒，不提前暴露具体结果。

### 6.4 惊魂匣

- 不主动攻击。
- 受到致死伤害时，先对玩家造成 `ceil(ResolvedMaxHP × 80%)` 爆炸伤害，再死亡。
- 若爆炸令玩家降至 -1，则直接失败。
- 数字战利品为 `ceil(ResolvedMaxHP × 50%)`。
- 额外从扳手、少女的心事、守护者之盾、魔药中等概率掉落 1 件。

### 6.5 鼓鼓仓鼠

- 前两个敌人回合各造成 2 点伤害并尝试偷取 3 Point。
- 实际偷取量不超过玩家当前可偷取点数，并累计到赃款。
- 第三个敌人回合携带赃款逃跑，释放占位，不产生奖励。
- 逃跑前被击杀时先返还全部赃款，再进入正常战利品结算。
- 普攻造成的伤害不返还。

### 6.6 哀叹之钟

一阶段：

- 25 HP，普攻 4。
- 循环为普攻、蓄力、蓄力、7 点强力击。

二阶段：

- 15 HP，普攻 3。
- 循环为普攻、普攻、偷取道具。
- 有道具时均匀随机永久移除 1 件。
- 无道具时造成 4 点伤害并眩晕玩家 1 回合。

阶段转换：

- 一阶段归零后不释放 2×2 占位，不结束战斗。
- 显示本地化键 `enemy.action.boss_phase_transition`。
- 保留玩家当前点数、背包和战斗状态，由玩家先行动。
- 二阶段归零后直接胜利；无战利品，不进入安全 / 贪婪。

### 6.7 敌人世界 UI

探索状态：

- 普通怪显示掉落规则，不显示战斗意图。

战斗状态：

- `HealthRoot` 显示生命。
- `HealthFill.fillAmount = CurrentHP / MaxHP`。
- `IntentImage` 根据当前意图显示对应图标。
- 鼠标悬停意图图标时显示 `IntentRoot` 与原有文字说明，移开后隐藏。
- 敌人行动只执行玩家回合已经展示并锁定的意图。

## 7. 普通怪战利品与贪婪

### 7.1 数字战利品

除惊魂匣外，普通怪使用：

```text
BattleLoot = ceil(ResolvedMaxHP × TurnMultiplier)
```

| 击杀所用玩家行动 | 倍率 |
|---:|---:|
| 1 | 80% |
| 2 | 70% |
| 3 | 60% |
| 4 | 50% |
| 5 及以后 | 45% |

- 普攻、技能、道具、挣扎都会增加行动数。
- 战斗消耗和受伤不会再从 BattleLoot 中重复扣除。
- 道具掉落在怪物死亡时直接加入背包，独立于数字奖励。
- 贪婪失败不会移除已获得的道具。

### 7.2 安全

- 领取 BattleLoot 的 100%。
- 不进行随机判定。

### 7.3 基础贪婪

- 初始成功率 50%。
- 成功获得 `floor(BattleLoot × 2.5)`。
- 失败获得 0 Point。
- 结果只在玩家确认后生成一次。

### 7.4 追加贪婪

持有破碎的镜子且首次贪婪成功后，可收手或继续：

| 下一次贪婪 | 成功率 |
|---:|---:|
| 第 2 次 | 40% |
| 第 3 次 | 30% |
| 第 4 次 | 20% |
| 第 5 次 | 10% |

- 每次成功独立增加一份 `floor(BattleLoot × 当前倍率)`。
- 追加失败时，该次增加 0，但保留此前已经成功累计的收益。
- 每次成功后都可以收手。
- 幸运硬币只影响第一次，不影响追加概率。

## 8. 道具与藏品

### 8.1 背包

- 道具和藏品统一由 `PlayerInventory` 保存。
- 当前 `limitItemSlots` 默认不启用，因此不是“只能持有四种道具”。
- 战斗二级菜单固定提供四个道具显示槽，对应当前四种道具类型。
- 同类自动堆叠；四种道具上限均为 99。
- 藏品按自己的 `maximumStacks` 限制。

### 8.2 道具

| 道具 | 当前效果 | 堆叠 / 限制 |
|---|---|---|
| 扳手 | 接下来 3 次玩家行动，普攻固定伤害 +2 | 可重复使用并叠加独立持续项 |
| 少女的心事 | 抵消下一次仍有伤害的敌人攻击 | 状态已存在时不能再次使用 |
| 守护者之盾 | 下一个敌人阶段提供 6 点护盾 | 护盾存在时不能再次使用 |
| 魔药 | 立即回复 6 Point | 不超过 100 |

- 道具仅在玩家战斗回合使用。
- 使用后消耗 1 件、关闭行动菜单并进入敌人回合。
- 一回合只使用一个道具，因此心事和盾通常不会在同一回合新激活。
- 状态图标使用道具效果文件夹中的扳手、盾、心脏图标。

### 8.3 藏品

| 藏品 | 堆叠 | 当前效果 | 耐久 |
|---|---:|---|---|
| 幸运硬币 | 最多 2 | 每个使第一次贪婪成功率 +7%；最高为 64% | 永久 |
| 饿狼 | 最多 1 | 贪婪倍率覆盖为 2.4× | 参与 3 场选择贪婪的战斗后破碎 |
| 破碎的镜子 | 最多 1 | 解锁 40% / 30% / 20% / 10% 追加贪婪 | 参与 3 场选择贪婪的战斗后破碎 |

耐久规则：

- 只有该场实际选择过贪婪，才在奖励流程结束时消耗一次耐久。
- 安全领取不会消耗。
- 每份藏品实例单独记录剩余贪婪战斗次数。

## 9. 世界事件

所有事件都由 `WorldInteractable` 与 `WorldInteractionContext` 统一管理。`context.Complete()` 默认消费并移除事件；`context.Complete(consume: false)` 关闭面板但保留事件。

### 9.1 篝火

- 打开时复用 `CampfirePanel`。
- 休息：在 `[5, 10]` 闭区间随机回复，受 100 上限限制；随后消费篝火。
- 离开：关闭面板但不消费篝火，可再次访问。

入口：`CampfireInteractable.cs`、`CampfirePanel.cs`。

### 9.2 商店

- 使用 Point 购买，购买本身不推进探索回合。
- 每条商品配置有价格与库存；售罄后不能再次购买。
- 关闭 / 离开商店会消费该商店并释放占位。
- 购买后点数允许降到 0，不允许降到 -1。

当前三个库存资产：

| 配置 | 商品 |
|---|---|
| `DefaultShopInventory` | 扳手 2；魔药 4×2；盾 3 |
| `DefaultShopInventory 2` | 扳手 2×2；魔药 4×2；盾 3 |
| `DefaultShopInventory 3` | 扳手 2×2；魔药 4×2；盾 3；少女的心事 5 |

数字为单价；`×2` 表示配置中有两条各 1 库存的同类商品。

### 9.3 供奉

- 可选范围为 1 到 `min(15, 当前Point)`。
- 离开或完成供奉都会消费供奉点。
- 结果权重必须合计 100。

| 权重 | 结果 |
|---:|---|
| 35% | 获得随机道具 |
| 20% | 供奉点全部失去 |
| 30% | 扣除后返还供奉值 ×2 |
| 15% | 扣除后返还原供奉值 |

当前配置没有“攻击力提升”结果；代码保留该枚举与处理能力，但 `DefaultOffering.asset` 未使用。

随机道具数量：

| 供奉值 | 抽取数量 |
|---:|---:|
| 1～5 | 1 |
| 6～10 | 2 |
| 11～15 | 3 |

每件从四种道具中等权独立抽取，允许重复。若某件达到堆叠上限，仅该件领取失败，其余继续结算。

### 9.4 交换

- 面板复用 `ShopPanel`，但隐藏当前点数并显示 `exchange.prompt`。
- 只允许拿 1 件道具交换；藏品不参与。
- 候选池排除玩家交出的道具，并排除已达堆叠上限的目标。
- 从剩余合法种类中均匀随机获得 1 件。
- 只有成功找到目标后才扣除原道具。
- 没有道具或没有合法目标时交换失败，不扣物品。
- 成功或离开都会消费交换点。

### 9.5 宝藏

宝藏复用篝火面板。

技能宝藏：

- 三个 Prefab 分别给予嗜血、寄生、复仇。
- 面板 `Title` 显示技能名称，`PreviewText` 显示完整描述。
- 可学习时只显示“学习”，不显示“离开”。

道具 / 藏品宝藏：

- 奖励由 Prefab / 场景配置指定。
- `Title` 显示物品名称，`PreviewText` 显示完整描述。
- 可领取时只显示“领取”，不显示“离开”。

领取流程：

1. 加入技能或背包。
2. 关闭面板。
3. 显示已获得的 Toast。
4. 消费宝藏并释放占位。

若已经拥有技能、奖励无效或达到最大堆叠，领取不可用并允许离开；此时离开不消费宝藏，可稍后再访问。

## 10. UI、反馈与设置

### 10.1 常驻 HUD

- 当前 Point。
- Point 变化飘字。
- 四种道具的图标与数量。
- 已持有藏品图标。
- 悬停道具 / 藏品显示名称和完整说明。

不显示金币、经验值或独立玩家血条。

### 10.2 战斗菜单

一级菜单：

1. 普攻 / 0 点时的挣扎。
2. 技能槽 1。
3. 技能槽 2。
4. 技能槽 3。
5. 道具入口。

二级道具菜单显示 4 个道具槽和返回按钮。鼠标与键盘可混用。

### 10.3 玩家头顶状态

`PlayerBattleStatusWorldUI` 显示扳手、盾和心脏状态：

- 默认位于玩家头上。
- 若怪物占据玩家正上方格子，改为显示在玩家脚下。
- 离开战斗时整组隐藏。
- 状态失效后对应图标立即隐藏。

### 10.4 Toast

Toast 用于短时、不阻断流程的结果反馈，包括：

- 宝藏学习 / 领取结果。
- 战斗道具保护结果。
- 供奉、商店和交换结果。
- 安全 / 贪婪结果。

Boss 二阶段提示使用 `enemy.action.boss_phase_transition`，不得硬编码任一语言。

### 10.5 设置

SettingsPanel 包含：

- 音乐音量。
- 音效音量。
- 英文 / 简体中文 / 日文。
- 退出游戏。

`Esc` 可关闭设置面板。桌面版 `Application.Quit()` 退出程序；WebGL 浏览器通常不允许网页主动关闭标签页，因此退出按钮在 WebGL 中可能无可见效果。

### 10.6 胜负面板

失败：

- 显示 `FailTitleImage` / `titleImage` 美术。
- 隐藏 `WinTitleText`。

胜利：

- 隐藏失败图片。
- 显示 `WinTitleText`。
- 标题键 `game_over.victory_title`：
  - English：Victory
  - Chinese：胜利通关
  - Japanese：勝利

胜负面板都提供重试和返回标题。

## 11. 本地化与数据

### 11.1 本地化链路

```text
Assets/GameData/database.xlsx
→ Excel 导入流程
→ Assets/Resources/GameData/database.json
→ GameLocalization
→ 各 UI / Definition 的 DisplayName 与 Description
```

- 支持 `English`、`Chinese`、`Japanese`。
- 修改文本时应先改 Excel 源表，再重新导出 JSON。
- 若紧急修改 JSON，也必须同步 Excel，否则下次导表会覆盖。
- 名称 / 描述格式化参数使用 `{0}`、`{1}`。

### 11.2 配置资产

| 数据 | 路径 |
|---|---|
| 敌人 | `Assets/Game/Data/Enemies` |
| 技能 | `Assets/Game/Data/Skills` |
| 道具与藏品 | `Assets/Game/Data/Collectibles` |
| 商店库存 | `Assets/Game/Data/Shops` |
| 供奉 | `Assets/Game/Data/Offerings` |
| 音频映射 | `Assets/GameData/AudioInfoListSO.asset` |
| UI Prefab | `Assets/Resources/UI` |
| 敌人 Prefab | `Assets/Resources/Enemies` |
| 世界事件 Prefab | `Assets/Resources/World` |

ScriptableObject 中的中文 `displayName` / `description` 是本地化缺失时的回退；正常显示优先读取本地化键。

### 11.3 随机

`GameRandom` 统一用于：

- 怪物生命 Roll。
- 贪婪判定。
- 掠夺者喝酒结果。
- 惊魂匣道具掉落。
- 篝火回复。
- 供奉结果和道具。
- 交换目标。
- Boss 二阶段偷取的道具。

随机结果在逻辑结算时生成；UI 动画只展示结果。

## 13. 关键边界与维护注意

### 13.1 容易混淆的规则

- 玩家在 0 点仍活着，-1 才失败。
- 接触敌人或事件不扣移动点。
- 战斗菜单没有“防御”按钮。
- 扳手只增加普攻的加法部分；嗜血在加法后乘 2。
- 寄生只有击杀时回复 3。
- 复仇每击是 5，不是 4。
- 幸运硬币每个 +7%，不是 +10%。
- 饿狼是 2.4×，不是 3.5×。
- 饿狼和破碎镜子都只有 3 场“实际选择贪婪”的耐久。
- 供奉当前没有攻击力提升结果。
- 离开篝火和无效宝藏会保留事件；离开商店、供奉、交换会消费事件。
- Boss 当前生命为 25 + 15，不是早期设计的 50 + 30。

### 13.2 修改机制时的同步清单

修改数值或规则时至少检查：

1. 对应 ScriptableObject `.asset`。
2. `EncounterController` 或相关 Interactable 的特殊结算。
3. `database.xlsx` 三种语言说明。
4. 重新生成并核对 `database.json`。
5. 本 GDD 的速查表、具体章节和边界清单。
6. Prefab / 场景的序列化引用。
7. 新局、下一场战斗、Boss 转阶段和达到上限时的边界。
