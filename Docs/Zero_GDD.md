# 《归零》可执行游戏设计文档

> 版本：0.3（Game Jam 制作版）  
> 目标体验时长：10～30 分钟  
> 主题：COUNTDOWN  
> 类型：俯视角网格探索 + 回合制战斗 + 风险结算  
> 一句话体验：生命就是行动点；在迷雾地图中权衡路线、战斗与贪婪，在数字跌破 0 前击败 Boss。

---

## 0. 本版结论

### 0.1 核心体验

玩家从一个可配置数字开始。这个数字同时代表生命、地图行动点、技能消耗、商店货币、供奉筹码，以及通关前的总倒计时。

玩家探索被迷雾覆盖的网格地图，根据怪物头顶显示的掉落规则决定绕行或战斗。进入战斗后，玩家读取怪物下一回合意图并规划行动。普通怪的数字掉落由本次锁定生命和击杀所用回合共同决定；越快击杀，保留的生命比例越高。战斗胜利后可以安全领取全部战利品，也可以选择贪婪，冒险放大收益。玩家通过篝火、商店、供奉、藏品和道具调整风险，最终在数字跌破 0 前击败 Boss。

### 0.2 10～30 分钟范围

Game Jam 最终版只制作：

- 1 个完整关卡。
- 1 个 Boss。
- 3～4 种普通怪物。
- 1 个供奉实体。
- 1 个篝火。
- 1 个商店。
- 3 种藏品。
- 4 种消耗道具。
- 1 个普通攻击，技能框架支持扩展。
- 每场普通怪物战斗前进行一次独立的生命 Roll/不 Roll 选择。

不制作多关卡战役、永久成长、随机关卡、复杂装备栏、大段剧情或超过 4 种普通怪物。

### 0.3 目标节奏

| 阶段 | 时间 | 内容 |
|---|---:|---|
| 探索与教学 | 2～4 分钟 | 移动、迷雾、首次战前生命选择 |
| 中段构筑 | 5～12 分钟 | 贪婪、供奉、篝火、商店 |
| 终局准备 | 2～5 分钟 | 最后的补给、构筑或绕路 |
| Boss 战 | 2～5 分钟 | 读取意图并完成资源终局 |

目标首局约 15～20 分钟，熟练玩家约 10～15 分钟，谨慎探索玩家不超过 30 分钟。

## 1. 设计支柱

1. **数字就是一切**：任何强力选择都直接或间接影响玩家的剩余数字。
2. **未知路线，已知风险**：地图有迷雾；探索时清晰显示已发现怪物的掉落规则，战斗时清晰显示当前怪物的下一回合意图。
3. **战斗不是默认答案**：玩家应根据路线成本、怪物生命、掉落数字和当前构筑决定是否开战。
4. **贪婪是主动选择**：高风险收益不能暗中触发，必须由玩家在清晰概率下确认。
5. **失败可以复盘**：玩家应知道数字消耗在移动、技能、受伤、商店、供奉还是贪婪失败上。

## 2. 核心规则总表

以下数值必须支持配置。

| 行为 | 默认数字变化 | 是否推进回合 |
|---|---:|---|
| 地图移动 1 格 | -1 | 是 |
| 地图等待 | -1 | 是 |
| 普通攻击 | -1 | 是 |
| 怪物普通攻击命中 | -10 | 已在怪物回合 |
| 使用道具 | 0 | 默认不推进；可按道具配置 |
| 尝试进入敌人格并触发遭遇 | 0 | 否 |
| 尝试进入交互物格并打开交互 | 0 | 否 |
| 商店购买 | -商品价格 | 否 |
| 供奉 | -玩家选择的点数 | 否 |
| 篝火恢复 | +配置区间内随机值 | 否 |
| 安全领取 | +100% 本场战利品 | 否 |
| 贪婪成功 | +本场战利品 × 2.5 | 否 |
| 贪婪失败 | +0 | 否 |

默认全局参数：

| 参数 | 默认值 |
|---|---:|
| 玩家初始数字 | 100 |
| 玩家死亡值 | -1 |
| 玩家数字上限 | 199 |
| 移动成本 | 1 |
| 等待成本 | 1 |
| 普攻成本 | 1 |
| 普攻伤害 | 3 |
| 普攻距离 | 曼哈顿距离 1 |
| 普通受击伤害 | 10 |
| 基础视野半径 | 1，即 3×3 |
| 贪婪基础成功率 | 50% |
| 贪婪基础倍率 | 2.5 |

### 2.1 濒死与失败规则

- 玩家数字降到 -1 时立即失败；0 是仍然存活的濒死状态。
- 除探索阶段的致死一步外，主动行为只有在结算行动成本后仍大于等于 0 时才合法。
- 数字为 1 时，可以执行一次成本为 1 的移动、攻击或技能并降到 0。
- 数字为 0 时，不能执行任何正成本主动行为，但仍可完成当前攻击、击杀和战利品结算。
- 探索阶段数字为 0 时，仍可向相邻空地移动最后一步；支付移动成本后降到 -1，完成移动表现后立即失败。
- 0 点撞敌人或交互物仍不支付移动成本，分别进入战斗或交互流程。
- 战斗中首次以 0 点进入玩家回合且没有其他合法行动时，可以进行一次零成本的濒死挣扎。
- 濒死挣扎用尽后再次以 0 点进入玩家回合且没有其他合法行动时，自动跳过玩家回合。
- 敌人攻击和环境伤害可以把玩家从 0 降到 -1。
- Boss 死亡后，玩家数字必须仍大于等于 0 才胜利。
- 任何界面消费都必须在确认按钮旁显示消费后的数字。

### 2.2 唯一资源原则

- 藏品是被动效果，不可消耗。
- 道具是一次性战术资源，不是货币。
- 商店支付玩家数字，不新增金币。
- 供奉支付玩家数字，不新增祭品。
- 怪物掉落的数字直接补充玩家数字。

## 3. 整局流程

```text
标题
→ 新游戏
→ 进入迷雾地图
→ 探索 / 交互
→ 触发普通怪物遭遇
→ 针对当前怪物选择 Roll / 不 Roll
→ 锁定当前怪物生命
→ 战斗
→ 战斗胜利结算：安全或贪婪
→ 继续探索并准备终局
→ Boss 战
→ 胜利或跌破 0 失败
→ 统计与立即重试
```

### 3.1 完成与失败

胜利需要 Boss 被击败，且玩家最终数字大于等于 0。

失败条件：

- 玩家数字降到 -1。

### 3.2 重开

- 暂停菜单和失败界面均提供立即重开。
- 重开恢复地图迷雾、实体状态、怪物生命、商店库存和玩家状态。
- 重开后直接进入地图；首次触发各普通怪物遭遇时再显示对应的生命选择界面。
- 从点击重开到重新可操作应少于 2 秒。

## 4. 战前决定当前怪物生命

### 4.1 触发时机

- 普通怪物第一次进入战斗时，在任何攻击、技能成本和怪物行动结算前暂停回合。
- 玩家向相邻敌人占据的目标格输入移动时触发遭遇；玩家位置不变。
- 只针对当前怪物实例打开一次选择界面；已经确定生命的实例不会再次选择。
- Boss 不显示该界面，两个阶段固定使用配置生命 50 和 30。

### 4.2 界面

界面必须同时显示当前怪物的名称、生命区间和掉落规则：

```text
小绒鸡
生命范围：8～12
掉落：锁定生命 × 80%～45%（随击杀回合衰减）

[ROLL]  在 8～12 中随机生命
[不 ROLL] 使用稳定生命
```

按钮下必须说明两种结果；掉落规则不能与生命使用同一个标签或视觉组件。

### 4.3 不 Roll

怪物固定生命：

```text
固定生命 =
min(最大生命, floor((最小生命 + 最大生命) / 2) + 1)
```

示例：

| 区间 | 固定生命 |
|---|---:|
| 3～7 | 6 |
| 5～10 | 8 |
| 8～14 | 12 |

### 4.4 Roll

- 只为当前遭遇的怪物实例在 `[MinHP, MaxHP]` 闭区间内均匀随机。
- Roll 只影响怪物生命，不改变攻击力、行为循环和掉落倍率；由于普通怪数字掉落以锁定生命为基数，Roll 结果会影响最终掉落点数。
- 不同实例、不同遭遇可以得到不同生命。
- 结果生成后立即保存为该实例的 `ResolvedMaxHP`，同时将当前生命设为相同值。
- Roll 动画只展示已经生成的结果，不负责产生随机数。

### 4.5 生命锁定

- 怪物实例拥有 `IsHealthResolved` 状态。
- 第一次选择后设为 `true`，本场战斗内不得重新 Roll。
- 战斗期间玩家位置锁定，不能通过地图移动中断遭遇。
- 重新加载当前局面时必须恢复已锁定的最大生命和当前生命。

### 4.6 设计目的

- 不 Roll：略高于平均值，结果稳定，适合规划。
- Roll：可能得到更低生命并节省数字，也可能增加战斗成本。
- 每场独立选择让玩家根据当前数字、掉落和道具决定是否冒险。

### 4.7 验收

- 每个新普通怪物遭遇只显示一次生命选择。
- 不 Roll 时使用中位数向下取整 +1，并且不超过最大值。
- Roll 时所有结果都在配置区间内。
- 同一怪物实例不会再次 Roll。
- Roll 结果不改变回合掉落倍率或道具掉落表，但会改变以 `ResolvedMaxHP` 为基数计算的最终数字掉落。
- Boss 两个阶段均不显示生命选择界面。

## 5. 网格、移动与回合

### 5.1 地图规则

- 正方形网格，仅允许上下左右移动。
- 玩家出生在关卡配置的起始格。
- 每次方向输入只处理上下左右相邻的一个目标格。
- 墙和地图边界不可进入；输入无效，不收费、不推进回合。
- 可行走空地：支付移动成本，玩家进入目标格并推进回合。
- 敌人占位：玩家不移动、不支付移动成本，进入该敌人的战斗流程。
- 商店、篝火、供奉等交互物占位：玩家不移动、不支付移动成本，打开对应交互。
- 玩家与怪物的占位不能重叠。
- 战斗结束时玩家仍停留在触发战斗前的格子；即使敌人死亡，也不会自动进入敌人原先的占位。
- 交互结束时玩家位置不变，交互物消失并释放占位格。

### 5.2 单回合顺序

探索输入：

1. 玩家选择一个上下左右方向。
2. 读取相邻目标格及其占位。
3. 空地执行移动；敌人触发战斗；交互物打开交互；墙或越界则拒绝。
4. 只有实际进入空地才支付移动成本并推进探索回合。
5. 玩家成功进入新格后更新视野并检查胜负。

战斗输入：

1. 遭遇正式开始时生成并显示怪物的第一个意图，进入玩家回合。
2. 玩家查看行动预览和怪物已锁定的意图。
3. 检查攻击、技能、道具或濒死挣扎是否合法。
4. 支付对应行动成本。
5. 执行玩家行动并处理死亡。
6. 若敌人存活，进入怪物回合并执行已经展示的意图。
7. 处理伤害、状态和胜负。
8. 若战斗继续，生成并锁定下一条意图。
9. 进入新的玩家回合并显示该意图；若玩家为 0 点且没有合法行动，则按濒死规则处理。

### 5.3 输入锁

从行动确认到结算结束：

- 禁止新的游戏输入。
- 逻辑先结算，动画只展示结果。
- 可以加速表现，不能跳过逻辑。

### 5.4 路线预览

最低要求：

- 相邻空地显示移动后的数字。
- 敌人格显示将触发战斗，交互物格显示对应交互类型。
- 危险格显示可能承受的伤害。
- 会使玩家数字降到 -1 的主动行动显示禁止标记。

增强项：点击远处已探索格时显示最短路径和纯移动成本。

## 6. 视野与战争迷雾

### 6.1 默认视野

- 默认视野是以玩家为中心的 **3×3** 区域。
- 即视野半径 `VisionRadius = 1`。
- 包含玩家所在格和周围 8 格。
- 视野半径必须支持配置。

通用计算：

```text
可见条件：
abs(cell.x - player.x) <= VisionRadius
且 abs(cell.y - player.y) <= VisionRadius
```

`VisionRadius = 2` 时得到 5×5，`VisionRadius = 3` 时得到 7×7。

MVP 不计算墙体遮挡，只按方形范围显示。若试玩证明需要，再增加射线遮挡。

### 6.2 三种状态

每个格子拥有：

```text
Unexplored  未探索
Explored    已探索但不在当前视野
Visible     当前可见
```

| 状态 | 地形 | 静态实体 | 固定怪物 | 战斗意图 |
|---|---|---|---|---|
| 未探索 | 不显示 | 不显示 | 不显示 | 不显示 |
| 已探索 | 暗色显示 | 显示最后确认状态 | 显示已发现的位置标记 | 不显示 |
| 当前可见 | 正常显示 | 正常显示 | 探索时显示掉落规则 | 仅当前战斗显示 |

静态实体包括篝火、商店、供奉和固定机关。

### 6.3 探索更新

玩家成功进入新格后：

1. 计算新的当前可见格集合。
2. 原可见格转为已探索。
3. 新可见格标为当前可见和已探索。
4. 刷新迷雾显示。
5. 显示新进入视野的实体。
6. 新发现怪物显示掉落规则，不生成或显示战斗意图。

初始位置周围 3×3 在进入关卡时立即探索，不额外收费。

### 6.4 怪物与迷雾

- 未发现的怪物完全隐藏。
- 怪物首次进入视野后，其固定位置永久记录在已探索地图上。
- 怪物离开当前视野后只保留静态位置标记，隐藏模型细节、掉落规则、生命和战斗意图。
- 怪物不会在迷雾中移动或攻击；只有玩家朝相邻敌人格输入方向时才会触发战斗。
- 怪物没有视野或侦测逻辑，不会因为看见玩家、与玩家距离变化或玩家进入其周围区域而行动。
- 已完成交互并消失的地图实体立即从当前视野和已探索记录中移除。

### 6.5 表现

- 未探索：完全遮挡或高不透明迷雾。
- 已探索：地图保持可读，但降低亮度和饱和度。
- 当前可见：完整颜色。
- 新探索格用 0.15～0.25 秒淡出。

### 6.6 验收

- 初始只显示配置范围内的格子。
- 玩家每移动一格，视野正确更新。
- 已探索地形不会重新变成未探索。
- 未探索格不泄露怪物、商店或供奉。
- 已发现怪物离开当前视野后保留正确的固定位置标记。
- 修改视野半径无需改代码。

## 7. 遭遇与战斗

### 7.1 战斗单位

MVP 中，一个怪物实例构成一场战斗：

- 玩家向上下左右相邻的敌人占位格输入方向时触发遭遇；斜角输入不存在。
- 触发遭遇的输入不视为移动，不扣移动成本，也不改变玩家位置。
- 若该实例尚未决定生命，先完成第 4 节的 Roll/不 Roll 选择，再正式进入战斗。
- 遭遇开始后锁定玩家位置，战斗期间不能执行地图移动。
- 该怪物死亡时战斗结束。
- 普通怪物死亡时释放原占位，但玩家不进入该格。
- 完成安全/贪婪结算后解除移动锁并恢复探索。

### 7.2 玩家战斗数据

| 字段 | 默认值 | 说明 |
|---|---:|---|
| 基础攻击力 | 3 | 普攻基础伤害 |
| 普攻消耗 | 1 | 从玩家数字扣除 |
| 普攻距离 | 1 | 曼哈顿距离 |
| 道具槽位 | 无限制 | 当前版本不限制持有的道具种类 |
| 藏品槽位 | 无限制 | 内容量较少 |

### 7.3 普通攻击

- 只能攻击当前遭遇中的怪物。
- 消耗玩家数字 1。
- 造成 3 点基础伤害。
- 必定命中。
- 没有合法目标时不允许空挥，也不收费。

```text
普通攻击伤害 =
floor(max(1, 基础攻击力 + 固定攻击加成) × 伤害倍率)
```

### 7.3.1 濒死挣扎与自动跳过

- 玩家数字为 0、没有其他合法行动且本场尚未挣扎时，显示“挣扎”。
- 挣扎消耗 0，造成 1 点伤害，每场战斗只能使用一次。
- 挣扎会正常推进回合；若没有击杀怪物，则怪物执行已展示的意图。
- 挣扎用尽后，玩家再次以 0 点进入回合且没有其他合法行动时，显示短暂提示并自动跳过。
- 自动跳过不消耗数字，怪物随后执行已展示的意图。
- 若以后加入可在 0 点使用的道具或技能，应先允许玩家操作，不能提前自动跳过。

### 7.4 怪物生命与掉落

- 怪物拥有独立生命值。
- 普通怪物的最大生命只由本次战前 Roll/不 Roll 结果决定。
- 生命值不是可夺取数字；普通怪的 `ResolvedMaxHP` 是回合掉落的计算基数。
- 当前生命和已经锁定的最大生命在战斗开始后公开。
- 怪物生命降到 0 时死亡。
- 普通怪数字掉落由 `ResolvedMaxHP × 当前击杀回合倍率` 决定，结果向上取整。
- 不推进回合的道具不增加击杀回合数；普通攻击和濒死挣扎各增加 1。
- 道具掉落由独立配置的 `ItemDropTable` 决定。

这取代 v0.1 的“破防格”和“攻击同时削减怪物数字”规则。

### 7.5 技能扩展框架

所有攻击使用统一技能数据：

| 字段 | 说明 |
|---|---|
| `SkillId` | 唯一 ID |
| `DisplayName` | 名称 |
| `NumberCost` | 数字消耗 |
| `BaseDamage` | 基础伤害 |
| `Range` | 攻击距离 |
| `TargetPattern` | Single / Line / Cross / Area |
| `CooldownTurns` | 冷却；普攻为 0 |
| `AdvancesTurn` | 是否推进回合 |
| `EffectIds` | 附加效果 |

普通攻击配置：

```text
SkillId: BasicAttack
NumberCost: 1
BaseDamage: 3
Range: 1
TargetPattern: Single
CooldownTurns: 0
AdvancesTurn: true
```

### 7.6 伤害预览

瞄准怪物时显示：

- 玩家行动前后数字。
- 本次预计伤害。
- 怪物行动后剩余生命。
- 是否会击杀。
- 若不会击杀，怪物下一回合意图和玩家可能损失。

## 8. 怪物与意图

### 8.1 共通结算规则

- 普通怪物的最终数字掉落由本次锁定生命和击杀所用玩家回合数共同决定。
- 第一次推进回合的玩家行动击杀算第 1 回合；每次普通攻击或濒死挣扎使回合计数增加 1。
- 使用默认不推进回合的道具不增加回合计数。
- 所有小数均向上取整：

```text
普通怪数字掉落 =
ceil(ResolvedMaxHP × 当前击杀回合倍率)
```

| 击杀回合 | 掉落倍率 |
|---:|---:|
| 1 | 80% |
| 2 | 70% |
| 3 | 60% |
| 4 | 50% |
| 5 及以后 | 45% |

- 该规则取代旧版的固定 `RewardNumber - AccumulatedNumberLoss`；战斗成本和怪物伤害不会再次从掉落中扣除。
- 仓鼠偷走的数字属于独立赃款，不影响上述掉落计算。
- 惊魂匣使用自身的 50% 数字掉落规则，并额外掉落 1 个随机道具。
- 最终数字掉落确定后，再进入安全或贪婪结算。

### 8.2 五种怪物

| 怪物 | 生命 | 基础攻击 | 技能 | 技能效果 | 行为循环 | 掉落 |
|---|---:|---:|---|---|---|---|
| 小绒鸡 | 8～12，战前决定 | 2 | 啄地 | 强力击，造成 3 点伤害 | 不攻击 → 普攻 → 啄地 | 锁定生命 × 回合倍率 |
| 发条油掠夺者 | 15～18，战前决定 | 4 | 烂醉如泥 | 喝酒后随机获得下次普攻 +1、自伤 2 或本回合晕眩 | 普攻 → 喝酒 | 锁定生命 × 回合倍率 |
| 惊魂匣 | 4～8，战前决定 | 0 | 负荷 | 吸收伤害，受到致死伤害时先爆炸 | 不攻击 | 锁定生命 × 50% + 随机道具 1 个 |
| 鼓鼓仓鼠 | 6～12，战前决定 | 0 | 土遁 | 前三个敌人回合各偷取 3 点；第四个敌人回合逃跑 | 偷取 → 偷取 → 偷取 → 逃跑 | 返还赃款 + 锁定生命 × 回合倍率 |
| 衰叹之钟·一阶段 | 固定 50 | 5 | 上发条 | 蓄力后造成 13 点强力攻击 | 普攻 → 蓄力 → 蓄力 → 强力击 | 无 |
| 衰叹之钟·二阶段 | 固定 30 | 7 | 挽歌 | 偷取道具；无道具时造成 5 点伤害并眩晕 1 回合 | 普攻 → 普攻 → 偷取 | 无 |

#### 小绒鸡

- 固定循环为“不攻击 → 普攻 → 啄地”。
- 啄地造成 3 点伤害。

#### 发条油掠夺者

- 使用浣熊美术素材。
- 固定循环为“普攻 → 喝酒”。
- 喝酒占用本回合，只预告“喝酒”，不提前公开具体结果。
- 喝酒结果为强化、自伤、晕眩，默认各 1/3，支持独立权重配置。
- 强化使下一次普攻伤害 +1；该次普攻执行后消耗强化，不叠加。
- 自伤使自身生命 -2，可以导致死亡；自行死亡仍正常计算数字掉落并进入安全/贪婪。
- 晕眩时当前喝酒回合无事发生，不攻击，也不附加后续状态。

#### 惊魂匣

- 不主动攻击。
- 受到致死伤害时，先造成 `ceil(ResolvedMaxHP × 80%)` 的爆炸伤害，再死亡。
- 若爆炸使玩家数字降到 -1，则直接失败，不进入掉落结算。
- 正常击杀获得 `ceil(ResolvedMaxHP × 50%)` 点数字，并根据独立 `ItemDropTable` 获得 1 个随机道具。

#### 鼓鼓仓鼠

- 前三个怪物回合各偷取 3 点，不造成普攻伤害。
- 玩家拥有第 4 个玩家回合的击杀机会。
- 若第 4 个玩家回合结束时仍未击杀，第四个怪物回合开始时携带最多 9 点逃跑，不再攻击或偷取。
- 偷取量记录在独立赃款字段中，不计入 `AccumulatedNumberLoss`。
- 在第 1～4 个玩家回合内被击杀时，先全额归还赃款，再按锁定生命和击杀回合计算数字掉落。
- 成功逃跑时怪物从原地消失并释放占位，本场遭遇结束，赃款永久失去，不产生掉落或贪婪结算。

#### 衰叹之钟

- Boss 不参与战前 Roll。
- 一阶段：固定生命 50，基础攻击 5，循环“普攻 → 蓄力 → 蓄力 → 13 点强力击”。
- 二阶段：固定生命 30，基础攻击 7，循环“普攻 → 普攻 → 偷取”。
- 偷取时从玩家背包均匀随机且永久移除一件道具。
- 没有道具时，改为造成 5 点伤害并眩晕玩家 1 回合。
- 一阶段结束后保留玩家状态，生成二阶段意图，并由玩家先行动。
- 击败二阶段立即胜利；不归还道具，不产生数字或道具掉落，不进入安全/贪婪。

### 8.3 怪物配置

| 字段 | 说明 |
|---|---|
| `EnemyId` | 唯一 ID |
| `MinHP` / `MaxHP` | Roll 生命区间 |
| `CanRollHP` | 是否显示战前生命选择；普通怪物为 true，Boss 为 false |
| `FixedHP` | 不参与 Roll 的固定生命，供 Boss 阶段使用 |
| `RewardMode` | 回合倍率、固定数值或特殊掉落 |
| `RewardNumber` | 固定数值掉落模式使用；普通小怪不使用 |
| `ItemDropTable` | 独立道具掉落表；无道具掉落时为空 |
| `AttackDamage` | 攻击伤害 |
| `AttackRange` | 攻击距离 |
| `Size` | 矩形占位尺寸；普通怪物默认 1×1，Boss 默认 2×2 |
| `BehaviorType` | 固定战斗行为类型 |
| `IntentSequence` | 固定意图循环 |

运行时的单个怪物实例至少保存：

| 字段 | 说明 |
|---|---|
| `IsHealthResolved` | 是否已经完成本实例的 Roll/不 Roll |
| `ResolvedMaxHP` | 本次遭遇锁定的最大生命 |
| `CurrentHP` | 当前生命 |
| `BattleRound` | 已执行的推进回合玩家行动数，用于掉落倍率 |
| `NextAttackBonus` | 掠夺者下一次普攻的临时加成 |
| `StolenNumberEscrow` | 仓鼠赃款，不参与累计损失 |

### 8.4 怪物意图

怪物只有进入正式战斗后才生成意图。玩家回合期间，当前战斗怪物在头顶显示下一次怪物回合将执行的意图：

- 普通攻击：武器图标、目标格、伤害数字。
- 喝酒：酒瓶图标；只预告喝酒，不提前公开具体随机结果。
- 蓄力：蓄力图标和下一次攻击范围。
- 防御：盾牌和减伤值。
- 等待：沙漏图标。

攻击意图必须显示攻击范围、目标格，以及玩家若未击杀或控制怪物将受到的数字损失。

- 探索阶段的怪物头顶只显示掉落规则，不显示攻击、喝酒、等待或其他战斗意图。
- 怪物回合只执行玩家回合中已经展示的意图，不得临时替换。

### 8.5 意图生成

- 关卡开始、怪物被发现和玩家在地图上移动时都不生成意图。
- 普通怪物完成 Roll/不 Roll、正式进入战斗后，生成第一条意图并进入玩家回合。
- Boss 进入战斗后直接生成第一阶段的第一条意图并进入玩家回合。
- 玩家行动结束且怪物仍存活时，怪物执行当前已锁定意图。
- 怪物回合结算完成且战斗继续时，生成下一条意图并在新的玩家回合显示。
- 怪物受到控制、死亡或目标失效时更新。
- 随机意图必须在显示时完成随机，显示后不得暗改。
- 掠夺者的攻击/喝酒意图在显示时锁定；喝酒的具体效果在执行喝酒时才随机。

### 8.6 固定怪物规则

- 所有怪物由关卡预先放置，不巡逻、不追踪、不改变占位。
- 普通怪物默认占据 1×1；Boss 默认占据 2×2，均支持矩形尺寸配置。
- 玩家不能进入怪物占据的任何格子。
- 玩家向上下左右相邻的任意敌人占位格输入方向时触发该敌人的遭遇。
- 多格怪物的每个外沿占位格都可作为触发目标；玩家不会进入目标格。
- 怪物没有视野、侦测范围或主动接敌能力。
- 怪物只有在遭遇触发后才按意图循环行动。
- 怪物实例最终死亡或成功逃跑时释放全部占位格；Boss 第一阶段结束不释放。

## 9. 战斗结算：安全与贪婪

### 9.1 本场战利品

```text
普通怪数字战利品 =
ceil(ResolvedMaxHP × 当前击杀回合倍率)

惊魂匣数字战利品 =
ceil(ResolvedMaxHP × 50%)
```

- 普通怪的掉落倍率依次为 80%、70%、60%、50%、45%；第 5 回合后保持 45%。
- 数字战利品受 Roll 出的锁定生命影响。
- 战斗中的攻击成本、受到的伤害和仓鼠赃款不会再次从战利品中扣除。
- 本场数字战利品暂存在结算框中，尚未加入玩家数字。

道具掉落与数字战利品分开：

- 道具根据独立的 `ItemDropTable` 生成，并在怪物死亡时立即进入背包。
- 惊魂匣固定从自身道具表随机掉落 1 个道具。
- 贪婪失败不会移除本场获得的道具。
- 藏品默认通过商店或供奉获得。
- Boss 不生成任何战利品，也不打开安全/贪婪界面。

### 9.2 确认框

```text
锁定生命：12
击杀回合：2
掉落倍率：70%
本场数字：9

[安全领取]
获得 9（100%）

[贪婪]
50% 获得 22
50% 获得 0
道具不会丢失
```

必须同时显示概率和实际结果数字。

### 9.3 安全

- 获得本场战利品的 100%。
- 不进行随机判定。
- 结算后立即返回地图。

### 9.4 贪婪

- 基础成功率 50%。
- 成功获得本场战利品的 2.5 倍。
- 失败失去全部本场数字战利品。
- 保留本场获得的道具。

```text
成功收益 = floor(本场战利品 × 贪婪倍率)
失败收益 = 0
```

### 9.5 随机结果

- 进入结算框时只展示概率，不提前生成结果。
- 玩家点击贪婪并确认后生成一次结果。
- 结果生成后立即保存，不能通过暂停或关闭界面重抽。
- 使用统一随机数服务，支持测试固定 Seed。

### 9.6 结算顺序

1. 怪物死亡。
2. 根据怪物掉落模式、`ResolvedMaxHP` 和击杀回合生成本场数字战利品。
3. 惊魂匣等特殊怪物结算独立道具掉落。
4. 仓鼠若被击杀，独立归还赃款。
5. 将本场数字战利品暂存，不立即加入玩家数字。
6. 若本场数字战利品大于 0，打开安全/贪婪确认框。
7. 玩家选择并应用藏品对概率、倍率和追加贪婪的修改。
8. 生成结果并将最终收益加入玩家数字。
9. 处理数字上限和溢出。
10. 关闭结算框并恢复地图。

若怪物只有道具掉落且本场数字战利品为 0，则展示道具获得结果后直接返回地图，不弹出无意义的安全/贪婪选择。

### 9.7 验收

- 安全领取永远获得 100%。
- 基础贪婪成功时，12 变为 30。
- 基础贪婪失败时，数字收益为 0。
- 贪婪失败不删除已掉落道具。
- 结算框打开时其他怪物不会行动。
- 第 1～5 回合倍率依次为 80%、70%、60%、50%、45%，第 6 回合仍为 45%。
- 所有倍率结果向上取整。
- Roll 出的锁定生命变化会正确影响最终数字掉落。
- 战斗成本和怪物伤害不会从已经按回合衰减的掉落中再次扣除。

## 10. 藏品

### 10.1 通用规则

- 藏品是本局持续生效的被动物品。
- 不会消耗。
- 藏品没有全局持有数量上限。
- 同名藏品能否叠加由配置决定。
- 达到该藏品自身的堆叠上限后，不能再次购买或获得。
- 商店和供奉是主要来源。

### 10.2 幸运硬币

```text
每层使第一次贪婪成功率 +10%
基础成功率 50%
```

| 层数 | 成功率 |
|---:|---:|
| 0 | 50% |
| 1 | 60% |
| 2 | 70% |
| 3 | 80% |

默认成功率上限 90%，支持配置。

### 10.3 饿狼

- 贪婪成功倍率从 2.5 倍改为 3.5 倍。
- 不改变成功率。
- MVP 不可叠加。

### 10.4 破碎的镜子

- 贪婪成功后，可以再次对当前累计收益进行贪婪。
- 每层增加一次追加贪婪机会。
- 最多 4 层。

| 追加次数 | 成功率 |
|---:|---:|
| 第 1 次 | 50% |
| 第 2 次 | 40% |
| 第 3 次 | 30% |
| 第 4 次 | 20% |

追加规则：

- 只有上一次成功才出现下一次确认。
- 玩家可以选择“收手”，立即领取当前累计收益。
- 追加成功：累计收益再次乘以当前贪婪倍率。
- 追加失败：本场累计数字收益归零。
- 道具始终保留。
- 幸运硬币默认只影响第一次贪婪。
- 饿狼影响第一次和追加贪婪倍率。

示例：本场战利品 10，拥有饿狼和 1 层镜子。

```text
第一次成功：10 × 3.5 = 35
追加成功：35 × 3.5 = 122
追加失败：0
```

### 10.5 展示

- HUD 显示藏品图标。
- 悬停显示规则、层数和当前实际数值。
- 贪婪确认框显示修改后的概率和倍率。

## 11. 道具

### 11.1 通用规则

- 道具是在战斗中使用的一次性物品。
- 使用后消耗 1 个。
- 默认不消耗玩家数字。
- 当前 4 种道具使用后都不推进回合，并自动返回一级战斗菜单。
- 道具只允许在战斗中的玩家行动阶段使用；常驻 HUD 只负责展示。
- 当前版本不限制背包中的道具种类，同类道具自动堆叠。
- 每种道具的堆叠上限独立配置，MVP 默认上限为 99。
- 达到单种道具堆叠上限后，新获得的同类道具只能放弃。
- MVP 不制作道具替换界面；若后续重新启用槽位限制，再补充替换流程。

### 11.2 扳手

- 使用后 3 个玩家回合内基础攻击力 +2。
- 使用后的当前玩家回合计为第 1 回合。
- 重复使用时数值可叠加，每次使用独立计算 3 个玩家行动的持续时间。

```text
AttackBonus: +2
DurationPlayerTurns: 3
AdvancesTurn: false
```

### 11.3 少女的心事

- 添加一次性替伤状态。
- 下一次怪物攻击伤害被完全抵消。
- 触发后移除。
- 环境伤害默认不触发。
- 不可叠加。

### 11.4 守护者之盾

- 为下一个敌人阶段提供 6 点护盾。
- 护盾先抵扣怪物攻击；超出 6 点的剩余伤害继续进入后续结算。
- 敌人阶段结束后消失。
- 不可叠加；护盾仍存在时不能再次使用。
- 可与少女的心事同时存在；护盾优先。

### 11.5 魔药

- 立即恢复玩家数字。
- 恢复 6 点。
- 不超过数字上限。
- 只允许在战斗中的玩家行动阶段使用。

### 11.6 效果顺序

受到攻击：

1. 判断守护者之盾。
2. 判断少女的心事。
3. 应用伤害。
4. 检查数字是否降到 -1。

造成攻击：

1. 读取技能基础伤害。
2. 应用扳手和供奉的固定攻击加成。
3. 应用倍率。
4. 应用怪物防御。
5. 取整并造成伤害。

## 12. 供奉

### 12.1 地图实体

- 供奉台是一次性静态实体。
- 发现后在已探索地图中保留标记，直到交互结束并消失。
- 玩家向相邻供奉台占位格输入方向时打开界面，玩家不移动。
- 交互本身不收费、不推进回合。
- 玩家未进行供奉而直接离开时，本次交互仍结束。
- 交互结束后供奉台消失并释放占位格。

### 12.2 输入

- 最小供奉 1。
- 最大值取配置上限和“玩家当前数字”中的较小值。
- 配置上限默认 100。
- 界面提供滑条和 `-10/-1/+1/+10`。
- 确认前显示供奉后的数字。
- 允许供奉后降到 0，但不能供奉到负数。
- 玩家当前数字为 0 时没有可供奉的数字，界面显示玩家处于濒死状态，并禁用供奉确认。

### 12.3 结果表

用户提供的概率合计为 80%。为得到完整可执行表，剩余 20% 暂定为返还原点数：

| 概率 | 结果 |
|---:|---|
| 10% | 获得 1 个随机道具 |
| 30% | 返回 0，点数全部失去 |
| 20% | 本局基础攻击力 +1 |
| 20% | 返回供奉点数的 2 倍 |
| 20% | 返回供奉点数的 1 倍 |

“返回 2 倍”表示扣除本金后再获得 `供奉点数 × 2`，实际净增等于供奉点数。

- 五种结果使用固定概率，供奉数量不改变概率。
- 供奉数量只影响全部失去、双倍返还和原数返还涉及的数字。
- 返还数字受到玩家数字上限限制。
- 基础攻击力提升持续到本局结束，影响普通攻击和技能，不增强 0 点挣扎。

### 12.4 结算

1. 输入供奉值。
2. 检查供奉值至少为 1，且供奉后仍大于等于 0。
3. 扣除供奉数字。
4. 生成一次随机结果。
5. 应用结果。
6. 播放明确反馈。
7. 移除供奉台并释放占位格。

### 12.5 随机道具

- 从配置的道具池按权重选择。
- 道具池只包含 `Item`，不包含藏品。
- 当前版本不限制道具种类，不触发替换流程。
- 抽到的道具已达到自身堆叠上限时，显示明确反馈并放弃该奖励。
- 即使道具因达到堆叠上限而被放弃，供奉也已完成。

## 13. 篝火

- 篝火是一次性静态实体。
- 玩家向相邻篝火占位格输入方向时打开界面，玩家不移动，也不推进回合。
- 交互结束后篝火消失并释放占位格。

默认在闭区间 `[5, 10]` 内均匀随机恢复：

```text
RestoreAmount = RandomInclusive(MinRestore, MaxRestore)
```

配置：

```text
MinRestore: 5
MaxRestore: 10
UseCount: 1
```

交互界面：

```text
休息后恢复 5～10
[休息] [离开]
```

- 恢复不超过数字上限。
- 满数字时使用需二次提示。
- 选择离开也会结束本次交互并移除篝火。
- MVP 不增加敌人刷新或额外时间成本。

## 14. 商店

### 14.1 基础规则

- 玩家向相邻商店占位格输入方向时打开界面，玩家不移动，也不推进回合。
- 以玩家数字支付。
- 售卖藏品和道具。
- 商品与价格由配置决定。
- 每件商品默认库存 1。
- 关闭商店界面后商店消失并释放占位格。

### 14.2 购买合法性

- 购买后玩家数字必须大于等于 0。
- 道具达到自身堆叠上限时不可购买。
- 藏品达到最大层数时不可购买。
- 显示购买前后数字和商品的实际效果。

### 14.3 首轮价格

| 商品 | 类型 | 建议价格 |
|---|---|---:|
| 幸运硬币 | 藏品 | 14 |
| 饿狼 | 藏品 | 20 |
| 破碎的镜子 | 藏品 | 18 |
| 扳手 | 道具 | 3 |
| 少女的心事 | 道具 | 5 |
| 守护者之盾 | 道具 | 3 |
| 魔药 | 道具 | 4 |

价格需在完整路线可玩后统一平衡。商店不是必经点，绕路也属于购买成本。

### 14.4 结束交互

- 可以不购买直接离开。
- 商品售罄后显示售罄。
- 关闭界面即结束本次商店交互；无论是否购买，商店都会从地图消失。
- 玩家位置始终保持不变，商店占位在消失后恢复为可行走空地。

## 15. 目标格触发与占位

- 所有普通怪物和 Boss 从关卡开始便固定在配置的网格位置。
- 怪物不巡逻、不追踪玩家，也不会因进入视野而主动接敌。
- 玩家每次输入只检查一个上下左右相邻目标格。
- 目标是空地时进入该格；目标是敌人时进入战斗；目标是交互物时打开交互。
- 敌人和交互物都不会被玩家踏入，触发前后玩家位置保持不变。
- 触发遭遇后锁定玩家位置，直到当前战斗及其结算全部完成。
- 普通怪物默认占据 1×1；Boss 默认占据 2×2。
- 普通怪物死亡后释放占位，并在安全/贪婪结算完成后恢复探索。
- Boss 第一阶段结束时保持原位置与占位，直接进入第二阶段；只有第二阶段死亡才释放占位。
- 交互物完成交互后立即消失并释放占位，不允许再次访问。
- Boss 所在区域从开局即可到达，是否前往只由路线成本、补给和玩家当前构筑决定。

## 16. Boss

### 16.1 衰叹之钟

- Boss 是关卡中固定放置的 2×2 怪物实体。
- Boss 默认不参与战前生命 Roll。
- 玩家向相邻的任意 Boss 占位格输入方向时进入 Boss 战；玩家保持原位并锁定移动。
- Boss 不产生数字或道具掉落。

| 阶段 | 最大生命 | 基础攻击 | 技能 | 行为循环 |
|---|---:|---:|---|---|
| 一阶段 | 50 | 5 | 上发条：蓄力后造成 13 点强力攻击 | 普攻 → 蓄力 → 蓄力 → 强力击 |
| 二阶段 | 30 | 7 | 挽歌：偷取道具；无道具时造成 5 点伤害并眩晕 1 回合 | 普攻 → 普攻 → 偷取 |

### 16.2 阶段转换

- 一阶段生命归零后不判定胜利。
- Boss 保持原位置和完整 2×2 占位，不解除战斗锁。
- 保留玩家数字、道具、藏品和状态，Boss 当前生命重置为二阶段固定生命 30。
- 生成二阶段的第一个意图，并由玩家先行动。
- 击败二阶段后立即检查胜利，不归还被偷道具，不生成战利品，也不打开安全/贪婪界面。

### 16.3 公平性

- 战斗期间下一回合意图始终可见。
- 一阶段的 13 点强力攻击提前显示蓄力过程。
- 不使用未公开随机攻击。
- Boss 死亡立即取消未执行意图。
- Boss 不触发安全/贪婪结算。

### 16.4 目标数值

- 普通玩家接敌时剩余 20～40。
- 熟练玩家可以无伤结束。
- 普通玩家承受一次强力攻击后仍可能胜利。
- 攻击增益应节省 2～4 次攻击行动。

## 17. 关卡结构

### 17.1 区域

1. **出生区**：展示 3×3 视野和移动扣点。
2. **首次战斗区**：教学普攻、意图、安全/贪婪。
3. **分叉探索区**：商店、篝火、供奉分别位于不同路线。
4. **终局准备区**：玩家决定继续补给、绕路或直接挑战 Boss。
5. **Boss 区**：放置 2×2 Boss 的开放战斗区域，从开局即可到达。

### 17.2 内容预算

| 项目 | 数量 |
|---|---:|
| 有效地图尺寸 | 24×18 左右 |
| 必经移动成本 | 30～45 |
| 普通怪物 | 4～6 |
| 供奉 | 1 |
| 篝火 | 1 |
| 商店 | 1 |
| Boss | 1 |

### 17.3 迷雾公平性

- 出生点 2～3 步内发现第一个目标。
- 关键分叉前给出地标、道路形状或声音提示。
- 商店、篝火和供奉首次进入视野时有独特提示。
- 不要求探索全部地图。
- 不把唯一可行路线藏在无提示死角。

### 17.4 路线成本

```text
真实成本 =
往返步数 + 战斗行动 + 预计受伤 + 购买/供奉支付
```

至少提供：

- 稳定路线：篝火 + 安全结算。
- 高风险路线：供奉 + 贪婪。
- 构筑路线：商店 + 藏品。

## 18. UI 与信息

### 18.1 常驻 HUD

- 玩家当前数字：最大视觉层级。
- 当前行动预览，如 `42 → 41`。
- 道具快捷栏，仅展示 4 个类型槽的图标和数量。
- 藏品图标。
- 鼠标悬停道具或藏品图标时，显示名称和完整介绍；提示框复用战斗道具介绍底图。

### 18.1.1 战斗行动菜单

- 一级菜单固定预留 5 个位置：普攻、3 个技能、道具。
- 尚未获得技能时只显示普攻和道具。
- 玩家为 0 点且本场仍可挣扎时，挣扎替换普攻按钮，不增加第 6 个按钮。
- 点击道具进入二级菜单，显示 4 个道具类型槽、当前数量和解释框。
- 点击可用道具后立即消耗并生效，不推进回合，自动返回一级菜单。
- 返回按钮只关闭道具二级菜单，不结束玩家回合。
- 战斗中的有效道具状态不占用行动菜单：在玩家脚下横向显示扳手、护盾和少女心事图标。
- 鼠标悬停状态图标时显示短标签，例如“扳手 +4”“护盾 6”“替伤 ×1”。
- 状态失效后对应图标立即消失；没有有效状态时整排隐藏。

不显示金币、经验条或传统玩家血条。

### 18.2 怪物世界 UI

探索阶段、尚未开始战斗：

```text
  掉落 12
```

此时显示怪物的掉落规则，例如“生命×80%～45%”；惊魂匣额外显示随机道具图标。探索阶段不显示生命、攻击力或战斗意图。

完成 Roll/不 Roll 并进入玩家回合后：

```text
  HP 7/10
  掉落 9（第2回合）
  意图：攻击 -2
```

- 当前战斗怪物的意图位于怪物头顶，并在每个玩家回合显示。
- 进入怪物回合后执行这条已锁定意图；若战斗继续，下一玩家回合显示新意图。
- 生命、掉落数字和意图必须视觉区分，避免把生命误认为可夺取数字。
- Roll 会更新生命；战斗中掉落预览根据锁定生命和当前预计击杀回合同步更新。

### 18.3 战前生命选择界面

- 显示当前怪物名称。
- 显示生命区间。
- 单独显示回合掉落规则或特殊道具掉落类型。
- `Roll` 按钮说明将在区间内随机。
- `不 Roll` 按钮直接显示将采用的固定生命。
- Boss 不打开该界面。

### 18.4 贪婪界面

根据当前藏品显示：

- 实际成功率。
- 实际成功倍率。
- 成功获得的整数。
- 失败获得 0。
- 道具保留说明。
- 镜子追加次数和下一次概率。

### 18.5 概率表现

- 使用数字百分比。
- 随机动画控制在 0.8～1.5 秒。
- 允许加速动画，但不能改变结果。
- 失败反馈强烈但不羞辱玩家。

### 18.6 教学顺序

1. `每走一步，数字 -1`
2. `朝敌人或地图实体移动会触发战斗或交互，但你会留在原地`
3. `你只能看见周围 3×3；走过的地图会保留`
4. `每场战斗前，选择随机生命，或使用稳定生命`
5. `生命决定战斗难度；掉落是另一个独立数值`
6. `普攻消耗 1，造成 3 点伤害`
7. `战斗开始后，怪物图标会告诉你下一回合要做什么`
8. `安全领取全部数字，或贪婪放大收益`
9. `你的数字也是商店货币和供奉筹码`
10. `在数字跌破 0 前击败 Boss`

## 23. 验收清单

### 23.1 核心数字

- [ ] 玩家默认从 100 开始。
- [ ] 玩家出生在关卡配置的有效起始格。
- [ ] 进入空地准确扣 1；触发敌人或交互物不扣移动成本。
- [ ] 探索阶段为 0 时仍可向相邻空地走最后一步，落地后变为 -1 并进入失败流程。
- [ ] 普攻准确扣 1 并造成 3 点伤害。
- [ ] 购买和供奉可以让玩家降到 0，但不能让玩家主动降到 -1。
- [ ] 玩家在 0 点完成击杀后可以通过结算奖励恢复。
- [ ] 玩家首次以 0 点且无其他合法行动进入战斗回合时，可以零成本挣扎一次并造成 1 点伤害。
- [ ] 挣扎用尽后再次以 0 点且无其他合法行动进入回合时，会提示并自动跳过。
- [ ] 存在其他合法的零成本行动时，不会自动跳过玩家回合。
- [ ] Boss 死亡后玩家大于等于 0 即可胜利。

### 23.2 迷雾

- [ ] 默认只显示玩家周围 3×3。
- [ ] 视野半径可配置。
- [ ] 已探索地形持续显示。
- [ ] 未探索格不泄露内容。
- [ ] 已发现怪物离开当前视野后保留固定位置标记。

- 供奉值和结果。
- 商店购买与篝火恢复。
- 接触 Boss 和通关时的数字。

### 24.2 目标指标

| 指标 | 目标 |
|---|---|
| 首局时长 | 15～20 分钟 |
| 熟练局时长 | 10～15 分钟 |
| 极限探索局 | 不超过 30 分钟 |

### 24.3 调整顺序

过难时按顺序调整：

1. 减少必经移动距离。
2. 减少怪物不可避免伤害。
3. 提高安全战利品。
4. 调低怪物生命区间。
5. 调低商店价格。
6. 最后才提高初始数字。
